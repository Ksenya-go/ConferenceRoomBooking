## ConferenceRoomBooking API
REST API for managing conference rooms, bookings, additional services, and reporting.
This project is a backend system for a company that rents conference rooms to businesses. 
It allows users to manage rooms and services, find available rooms, create bookings, calculate rental costs, and generate basic analytics.

## What the API can do
- Create and update conference rooms
- Create bookings with optional services
- Automatically calculate the booking price depending on the time of day
- Activate and deactivate rooms
- Attach additional services to rooms
- Search for available rooms by date, time, and capacity
- Check for conflicting bookings
- Generate occupancy, revenue, and popular services reports
